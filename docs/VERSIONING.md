# Versioning

Versioning and release policy are documented in [RELEASING.md](RELEASING.md).

The short form is:

```text
Nightly   0.4.0-nightly.312   # CI build from main, not tagged
RC        v0.4.0-rc.1         # tagged release candidate
Stable    v0.4.0              # tagged stable release
Patch     v0.4.1              # tagged stable patch
```

There is no permanent `develop` or `nightly` branch. See [DEVELOPMENT.md](DEVELOPMENT.md) for the branching model.
